# FFmpeg-UI 要求定義書

> **プロジェクト名**: FFmpeg-UI
> **作成日**: 2026-03-25
> **バージョン**: 1.0
> **ステータス**: ドラフト

---

## 1. プロジェクト概要

### 1.1 目的
FFmpegの全機能をモダンなGUIから操作できるデスクトップアプリケーション。
YouTube動画のダウンロード・プレビュー・編集をワンストップで行える統合メディアツール。

### 1.2 ターゲットユーザー
- 主要ユーザー: 開発者自身（作業効率化ツール）
- 将来的にAILEAPクライアントや一般公開も視野に入れる

### 1.3 対応プラットフォーム
- Windows 10/11
- macOS 12 (Monterey) 以降
- クロスプラットフォームビルド対応

## 3. 機能要求

### 3.1 コア機能一覧

#### F-01: YouTubeダウンロード + プレビュー
- **優先度**: P0 (MVP必須)
- **説明**: YouTube URLを入力し、動画情報を取得・プレビュー表示。
  任意のフォーマット・品質でダウンロード。
- **詳細要件**:
  - URL入力フィールド（ペースト検知で自動取得開始）
  - サムネイル表示、タイトル、チャンネル名、再生時間、利用可能フォーマット一覧
  - 動画プレビュー再生（ダウンロード前にストリーミングプレビュー）
  - フォーマット選択（映像+音声 / 映像のみ / 音声のみ）
  - 品質選択（4K / 1080p / 720p / 480p / 360p / 音声ビットレート）
  - ダウンロード進捗バー（速度・残り時間表示）
  - プレイリスト対応（一括ダウンロード / 個別選択）

#### F-02: 音声 / 映像分離・抽出
- **優先度**: P0 (MVP必須)
- **説明**: メディアファイルから音声トラック・映像トラックを分離抽出
- **詳細要件**:
  - ドラッグ&ドロップまたはファイル選択でメディア読み込み
  - ストリーム情報の表示（コーデック、ビットレート、サンプルレート等）
  - 音声のみ抽出（MP3 / AAC / WAV / FLAC / OGG 選択可）
  - 映像のみ抽出（音声除去）
  - マルチトラック対応（複数音声トラックの個別抽出）
  - 出力先フォルダ指定

#### F-03: 時間指定カット（トリミング）
- **優先度**: P0 (MVP必須)
- **説明**: 開始時間〜終了時間を指定してメディアをカット
- **詳細要件**:
  - ビジュアルタイムラインバー（ドラッグで範囲選択）
  - 秒単位の精密入力フィールド (HH:MM:SS.ms)
  - プレビュー再生（選択範囲のみ再生確認）
  - 再エンコードなしカット（-c copy）オプション
  - 再エンコードカット（フレーム精度）オプション
  - 複数区間カット → 結合（マルチセグメント）

#### F-04: フォーマット変換
- **優先度**: P0 (MVP必須)
- **説明**: メディアファイルのコンテナフォーマット変換
- **詳細要件**:
  - 対応フォーマット: MP4, WebM, MKV, MOV, AVI, FLV, TS, GIF
  - 音声フォーマット: MP3, AAC, WAV, FLAC, OGG, OPUS, WMA
  - コンテナ変換のみ（再エンコードなし）モード
  - 完全変換（再エンコード）モード
  - 変換プリセット（Web向け / SNS向け / アーカイブ向け等）

#### F-05: 解像度・ビットレート・コーデック設定
- **優先度**: P1
- **説明**: 映像・音声の詳細エンコード設定
- **詳細要件**:
  - 映像コーデック: H.264, H.265/HEVC, VP9, AV1, ProRes
  - 音声コーデック: AAC, MP3, OPUS, FLAC, PCM
  - 解像度プリセット: 4K / 1440p / 1080p / 720p / 480p / カスタム
  - アスペクト比設定（16:9, 4:3, 1:1, 9:16, カスタム）
  - ビットレートモード: CBR / VBR / CRF
  - フレームレート設定（24/25/30/48/50/60/カスタム）
  - 2パスエンコード対応
  - ハードウェアエンコード対応（NVENC, QSV, VideoToolbox検出・選択）
  - 出力ファイルサイズ推定表示

#### F-06: フィルター
- **優先度**: P1
- **説明**: FFmpegのビデオ/オーディオフィルターをGUIから適用
- **詳細要件**:
  - **映像フィルター**:
    - クロップ（視覚的な範囲指定UI）
    - 回転（90° / 180° / 270° / 任意角度）
    - 反転（水平 / 垂直）
    - スケール（リサイズ + パディング）
    - 字幕焼き込み（SRT / ASS ファイル読み込み）
    - テキストオーバーレイ（drawtext）
    - 画像ウォーターマーク
    - 色調補正（明るさ / コントラスト / 彩度 / ガンマ）
    - ぼかし / シャープネス
    - ノイズ除去（hqdn3d / nlmeans）
    - フェードイン / フェードアウト
    - 速度変更（0.25x 〜 4x）
    - 逆再生
    - インターレース解除（yadif）
  - **音声フィルター**:
    - 音量調整 / ノーマライズ
    - フェードイン / フェードアウト
    - ノイズ除去（afftdn / anlmdn）
    - イコライザー
    - 速度変更（atempo）
    - チャンネルレイアウト変更（ステレオ ↔ モノラル）
  - **フィルターチェーン**:
    - 複数フィルターの順序設定
    - フィルターごとのON/OFF切り替え
    - フィルター適用前後のプレビュー比較（Split View）
    - フィルターチェーンのプリセット保存・読み込み

#### F-07: バッチ処理
- **優先度**: P1
- **説明**: 複数ファイルに対して同一処理を一括適用
- **詳細要件**:
  - ファイルリスト（ドラッグ&ドロップ / フォルダ選択）
  - 共通設定の一括適用（フォーマット変換 / 解像度変更 / フィルター等）
  - 個別設定の上書き可
  - ジョブキュー表示（順序変更 / 一時停止 / キャンセル）
  - 並列処理数設定（CPUコア数に応じた推奨値）
  - 完了通知（OS通知 / サウンド）
  - 処理ログ表示
  - 出力ファイル名テンプレート（{name}_{resolution}_{date} 等）

#### F-08: ライブストリーミング関連
- **優先度**: P2
- **説明**: ストリームの録画・配信・変換
- **詳細要件**:
  - ストリームURL入力による録画（RTMP / HLS / DASH）
  - ストリーム → ファイル変換
  - ローカルファイル → ストリーム配信（RTMP出力）
  - ストリームのリアルタイムプレビュー
  - 録画スケジュール設定

### 3.2 FFmpegコマンド操作

#### プリセットモード（デフォルト）
- GUIの設定値から自動的にFFmpegコマンドを生成
- よく使う設定をユーザープリセットとして保存・管理
- ビルトインプリセット（Web向け、SNS向け、アーカイブ向け等）

#### コマンド直接編集モード
- 生成されたFFmpegコマンドをテキストエディタで直接編集可能
- コマンドのシンタックスハイライト
- コマンド履歴（過去に実行したコマンドの再利用）
- GUIで設定 → コマンド確認 → 手動調整 → 実行のワークフロー
- コマンドのインポート/エクスポート（共有用）

### 3.3 共通機能

#### S-01: FFmpeg / yt-dlp 自動セットアップ
- 初回起動時にFFmpegとyt-dlpの有無を検出
- 未インストールの場合、ダウンロードダイアログを表示
- OS別に適切なバイナリを自動取得
  - Windows: ffmpeg.exe / yt-dlp.exe（GitHub Releases）
  - macOS: ffmpeg / yt-dlp（GitHub Releases）
- ダウンロード進捗表示
- アプリ内蔵ディレクトリに配置（システムPATH不要）
- バージョンチェック＆自動アップデート機能

#### S-02: 国際化 (i18n)
- デフォルト言語: 日本語
- 対応言語: 日本語 / 英語
- 言語切り替えトグル（設定画面 + ヘッダー）
- next-intl によるメッセージ管理

#### S-03: テーマ
- ダークモード / ライトモード切り替え
- システム設定追従オプション
- Tailwind CSS のダークモード機能を活用

#### S-04: 設定管理
- 出力先デフォルトフォルダ
- 同名ファイル時の動作（上書き / リネーム / スキップ / 確認）
- 並列処理数
- 通知設定
- FFmpeg / yt-dlp バイナリパス
- ユーザープリセット管理
- 設定のエクスポート / インポート

#### S-05: ファイル管理
- ドラッグ&ドロップによるファイル読み込み
- 最近使ったファイル履歴
- 出力ファイルの自動命名規則
- 出力先フォルダのクイックオープン

## 4. UI/UX 要件

### 4.1 デザイン方針
- **品質レベル**: Awwwards級のモダンデザイン
- **テーマ**: ダーク/ライト切り替え対応
- **レイアウト**: タブ切り替え型

### 4.2 タブ構成
```
┌──────────────────────────────────────────────────────────┐
│  [FFmpeg-UI]   🌙/☀️  [JP/EN]  [⚙ 設定]                │
├──────────────────────────────────────────────────────────┤
│  [YouTube] [変換] [カット] [分離] [フィルター]           │
│  [バッチ] [ストリーム] [コマンド]                        │
├──────────────────────────────────────────────────────────┤
│                                                          │
│              各タブのメインコンテンツ                      │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  [ジョブキュー / 進捗バー]                               │
└──────────────────────────────────────────────────────────┘
```

### 4.3 タブ詳細

#### YouTube タブ
- URL入力バー（上部、ペースト自動検知）
- メディア情報カード（サムネイル + メタ情報）
- プレビュープレーヤー
- フォーマット/品質選択パネル
- ダウンロードボタン + 進捗

#### 変換タブ
- ファイル入力エリア（ドラッグ&ドロップ）
- 入力ファイル情報パネル
- 出力設定パネル（フォーマット / コーデック / 解像度 / ビットレート）
- プリセットセレクター
- 生成コマンドプレビュー
- 変換実行ボタン

#### カットタブ
- ファイル入力
- ビジュアルタイムライン（波形表示 + サムネイルストリップ）
- 開始/終了時間入力フィールド
- プレビュープレーヤー
- カットモード選択（高速コピー / フレーム精度）
- 実行ボタン

#### 分離タブ
- ファイル入力
- ストリーム一覧（映像 / 音声 / 字幕 各トラック）
- 抽出対象チェックボックス
- 出力フォーマット選択（トラック別）
- 実行ボタン

#### フィルタータブ
- ファイル入力
- フィルターカタログ（カテゴリ分類、検索）
- フィルターチェーンビルダー（適用順序のD&D並び替え）
- パラメータ調整パネル
- Before/After プレビュー（Split View）
- プリセット保存/読み込み

#### バッチタブ
- ファイルリスト（複数ファイルD&D）
- 共通処理設定
- ジョブキュー管理
- 一括実行 / 一時停止 / キャンセル

#### ストリームタブ
- ストリームURL入力
- 録画設定
- プレビュー
- 録画開始/停止

#### コマンドタブ
- FFmpegコマンドエディタ（シンタックスハイライト）
- コマンド履歴
- テンプレート / スニペット
- 実行ボタン + 出力ログ

### 4.4 デザインディテール
- アニメーション: Framer Motion によるスムーズなタブ遷移・パネル展開
- マイクロインタラクション: ホバーエフェクト、ボタンフィードバック
- タイポグラフィ: Noto Sans JP + Inter（英語）
- カラーパレット: 青〜シアン系のアクセントカラー（ダーク/ライト各テーマ）
- アイコン: Lucide React
- レスポンシブ: 最小ウィンドウサイズ 1024×768、リサイズ対応

### 4.5 ジョブキュー（常時表示フッター）
- 画面下部に常時表示されるジョブキューバー
- アクティブなタスクの進捗（プログレスバー + パーセンテージ + 速度 + 残り時間）
- キュー内タスク数表示
- 展開するとキュー全体のリスト表示
- 個別タスクの一時停止 / キャンセル / 優先度変更

## 5. 非機能要件

### 5.1 パフォーマンス
- アプリ起動: 3秒以内
- FFmpegコマンド生成: 即時（100ms以内）
- プレビュー表示: 2秒以内
- メモリ使用量: 通常時 200MB 以下
- FFmpeg処理中のUI応答性維持（非同期処理）

### 5.2 セキュリティ
- FFmpeg/yt-dlp バイナリのチェックサム検証
- ダウンロードはHTTPS経由のみ
- ユーザーデータのローカル保存のみ（外部送信なし）

### 5.3 エラーハンドリング
- FFmpegエラー出力のパース＆ユーザーフレンドリーなメッセージ表示
- ネットワークエラー時のリトライ機構
- クラッシュリカバリ（処理中断時のキュー復元）

### 5.4 アクセシビリティ
- キーボードショートカット（主要操作）
- ツールチップ（全ボタン/アイコン）

## 8. 技術的な考慮事項

### 8.1 Tauri 2 + Next.js の統合
- `@tauri-apps/api` を通じたRustバックエンドとの通信
- `invoke()` でRust側のコマンドを呼び出し
- `listen()` / `emit()` でイベントベースの進捗通知
- Next.js は SSG モードで動作（Tauri内蔵WebView）

### 8.2 FFmpeg プロセス管理
- Rust側で `std::process::Command` を使い非同期実行
- stderr のリアルタイムパースで進捗率を算出
- プロセスのキャンセル（kill シグナル）対応
- 複数プロセスの並行実行管理（Tokio タスク）

### 8.3 yt-dlp 統合
- JSON出力モード (`--dump-json`) でメタデータ取得
- フォーマット選択 (`-f` オプション) のGUI連携
- クッキー対応（ブラウザからのインポート）
- プレビュー用のストリームURL取得

### 8.4 ビデオプレビュー
- HTML5 `<video>` タグによるローカルファイル再生
- FFmpegによるサムネイルストリップ生成
- 波形データ生成（音声ファイル用）

### 8.5 クロスプラットフォーム対応
- Windows: FFmpeg/yt-dlp の .exe バイナリ
- macOS: Unix バイナリ + codesign 考慮
- パス区切り文字の統一処理（Rust側で吸収）
- ファイルダイアログのネイティブ統合

## 9. 用語定義

| 用語 | 定義 |
|------|------|
| ジョブ | FFmpegまたはyt-dlpの1つの実行タスク |
| プリセット | よく使うFFmpeg設定の保存セット |
| フィルターチェーン | 複数のFFmpegフィルターを連結した処理パイプライン |
| ストリーム | メディアファイル内の映像/音声/字幕トラック |
| コンテナ | メディアのファイルフォーマット（MP4, MKV等） |
| コーデック | 映像/音声の圧縮方式（H.264, AAC等） |
| CRF | Constant Rate Factor（品質基準エンコード） |
| CBR/VBR | 固定/可変ビットレート |
